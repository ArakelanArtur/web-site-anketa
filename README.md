# 📋 Web-site Anketa
Веб-приложение для заполнения анкеты, созданное с использованием современных технологий фронтенд-разработки. Проект представляет собой интерактивную форму с валидацией данных.

# 🚀 Стек технологий
HTML5 — семантическая структура документа.

CSS3 — стилизация и адаптивная верстка (использовался Flexbox/Grid).

JavaScript (ES6+) — логика работы формы, обработка данных и интерактивность.

Git — система контроля версий.

# ✨ Особенности
✅ Валидация полей: проверка корректности ввода перед отправкой.

📱 Адаптивный дизайн: сайт корректно отображается на ПК, планшетах и смартфонах.

🎨 Современный интерфейс: чистый и интуитивно понятный UI.
