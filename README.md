# 📋 Web-site 
Веб-приложение моих работ, созданное с использованием современных технологий фронтенд-разработки. Проект представляет информацию обо мне и показывает реализацию моих знаний.

# 🚀 Стек технологий
HTML5 — семантическая структура документа.

CSS3 — стилизация и адаптивная верстка (использовался Flexbox/Grid).

JavaScript — логика работы формы, обработка данных и интерактивность.

# ✨ Особенности

Адаптивный дизайн: сайт корректно переводится с русского на английский. 
Так же присуствует темная тематика сайта, при нажатии на кнопку Dark

# 📂 Структура проекта
index.html — основная разметка страницы.

css/ — папка со стилями.

js/ — логика приложения.

img/ — графические ресурсы.
